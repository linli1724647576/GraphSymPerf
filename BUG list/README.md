# Archived issue reports

Maintain submitted issues in the root [bugs.csv](../bugs.csv). It is the single registry for issue URLs, status evidence, and mappings to the current pattern catalog. The [registry guide](../README.md#submitted-issue-registry) defines its fields and counting rules.

This directory preserves historical report text and reproduction material, including reports that have not been submitted. Directory names such as `P3`, `P4`, or `S7` use earlier catalogs. Their numbers must not be copied into the current registry without checking the actual query pair.

The CSV keeps one row per submitted issue, including issues later grouped or declined upstream. Update statuses there instead of maintaining another summary table in this directory.

New or revised reports must follow [AGENTS.md](AGENTS.md). The existing [Neo4j path report](Neo4j/P3/BUG001.md) and [Neo4j Boolean report](Neo4j/P4/BUG002.md) provide writing examples; their measurements belong to their recorded experiments.
